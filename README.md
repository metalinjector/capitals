# ATLAS EUROPA — столицы Европы

Интерактивный учебный атлас на русском языке: **45 стран и столиц** из принятой в проекте европейской выборки, фотографии, истории и кроссворды.

Сайт: **https://capitals.zonner.site/**

## Возможности

- Шесть режимов викторины: три варианта ответа, ввод столицы, страна по столице, блиц на 60 секунд, экзамен и поиск страны на карте.
- Карта Европы (Natural Earth, 1:110m): можно рассматривать страны и открывать карточки, а в режиме викторины — находить страну по названию.
- Интервальное повторение: каждая карточка возвращается через 1, 3, 7, 16 и 35 дней; ошибки собираются в отдельную сессию «Повторить ошибки».
- Отбор вопросов по регионам, школьной программе и микрогосударствам.
- Атлас городов с фактами и фотогалереями; карточка каждой страны содержит языки, валюту, площадь, оценку населения, участие в ЕС, еврозоне и Шенгене.
- Отдельно отмечены исключения и нюансы: евро вне еврозоны, Берн как федеральный город, Амстердам и Гаага, Кипр, статистический охват населения и др.
- Генерация кроссвордов разных размеров с подсказками по странам или фактам; незавершённая сетка сохраняется.
- Игра на скорость «Поймай пару»: падающие плитки стран и столиц, восемь пар в раунде и три допустимые ошибки.
- Очки, серии ответов и история занятий в `localStorage` текущего браузера.
- Экспорт и импорт прогресса файлом — для переноса на другое устройство без аккаунта.
- Установка на телефон (PWA) и офлайн-работа: приложение кэшируется service worker-ом.
- Собственные адреса разделов (`#/atlas`, `#/map`, `#/falling`, `#/card/fr`, …), кнопка «Назад» работает.
- Звуковые сигналы с возможностью отключения.

Регистрация и серверная база данных не требуются. Прогресс хранится только на устройстве посетителя (ключи `atlas-europa-progress-v1`, `atlas-europa-crossword-v1`, `atlas-daily`); очистка данных сайта удаляет его — заранее скачайте файл прогресса в разделе «Прогресс».

## Актуальность и охват данных

- Статусы ЕС, еврозоны и Шенгена сверены **25 октября 2026 года** по материалам Еврокомиссии и Совета ЕС. Болгария отмечена в еврозоне с 1 января 2026 года; Болгария и Румыния — в Шенгене с 1 января 2025 года.
- Население — округлённая оценка ООН из *World Population Prospects 2024* на середину 2025 года; для Ватикана использована официальная оценка за 2024 год. Это не «живой счётчик» и не перепись. Для Украины, Кипра, Молдовы и отдельных территорий охват статистики особенно важен; пояснения вынесены в карточки.
- Площади округлены и могут отличаться по методике учёта территории. Население городов и годы «основания» удалены из карточек: исходные значения были несопоставимы по границам и источникам.
- В атласе 45 государств. Границы Европы трактуют по-разному; Турция, государства Южного Кавказа и Косово в текущую подборку не включены. Это ограничение набора данных, не утверждение об их географическом статусе.
- Справочные ссылки доступны прямо в карточке страны. Интересные исторические факты — редакционная подборка; для академических работ проверяйте первоисточники.

## Локальный запуск

Нужен Node.js 22.

```sh
npm ci
npm run dev
```

## Проверка и сборка

```sh
npm test
npx tsc --noEmit
npm run build
npm run preview
```

Готовая статика находится в `dist/`. Vite встраивает JavaScript и CSS в `index.html`; главное изображение копируется в `dist/images/`.

## Размещение через Docker и Caddy

```sh
docker network create web  # только если общая сеть ещё не существует
docker compose up -d --build
```

Внешний порт контейнера не публикуется: Caddy обращается к `capitals:80` через общую сеть `web`. Добавьте блок из `deploy/Caddyfile` в конфигурацию Caddy, проверьте её и выполните reload. DNS домена должен указывать на ваш сервер. Caddy автоматически выпускает HTTPS-сертификат. Проверка контейнера: `/healthz`.

Обновление:

```sh
git pull --ff-only
docker compose up -d --build
```

## Структура

- `src/App.tsx` — викторина, атлас, карта, статистика и обмен прогрессом.
- `src/EuropeMap.tsx`, `src/data/europeMap.ts` — карта Европы и её контуры.
- `src/Crossword.tsx`, `src/crosswordGen.ts` — кроссворды.
- `src/FallingPairs.tsx`, `src/fallingGame.ts` — игра на скорость «Поймай пару».
- `src/data/` — столицы, факты, профили стран, контуры карты и каталог фотографий.
- `src/data/countryProfiles.ts` — справочные данные о населении, площади, языках, валютах и членстве стран.
- `src/*.test.ts` — проверки данных, повторений, кроссворда и генерации пар для игры (`npm test`).
- `AUDIT.md` — результаты аудита, источники данных и приоритетные дальнейшие улучшения.
- `src/lib.ts` — подбор вопросов, проверка ответов, прогресс, интервальные повторения и звуки.
- `public/sw.js`, `public/manifest.webmanifest`, `public/icons/` — PWA и офлайн-режим.
- `scripts/fetch-wiki-*.mjs` — вспомогательное обновление каталога фотографий, не требуется для сборки.
- `deploy/` — примеры конфигурации веб-сервера.

Стек: React 19, TypeScript, Vite 7, Tailwind CSS 4.

Фотографии городов загружаются с Wikimedia Commons / Wikipedia, шрифты — с Google Fonts. Для них требуется интернет; права на сторонние материалы остаются у их авторов. Ссылки на справочные источники приведены в карточках городов.
